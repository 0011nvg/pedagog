## 21.10.2026 — рамки текущего этапа

Приложенный мастер-промпт требует сначала аудит без изменения исходников. Поэтому этот коммит добавляет только docs. Разрешение публиковать сохраняется и не требует повторного запроса для каждого технического исправления; оно не отменяет порядок этапов.

Существенные изменения философии, коммерческой модели и условий использования требуют отдельного решения автора. Рекомендации отчёта пока не считаются внедрёнными.

Не публикуем код доступа, незашифрованный платный комплект и частные файлы упаковки. Публичная документация описывает ограничения общего кода без раскрытия секрета.

Матрица разрешённых кодом составов не равна семантической экспертизе каждой возможной пары. 1900 случайных выдач проверяют соблюдение списка, а не педагогическую уместность самого списка.

## 30.10.2026 — редакция 4.0 (по финальному ТЗ автора)

- **Многоролевая модель.** В каждой ситуации 5–6 ролей из допустимого списка; 2–3 первые, остальные входят с тремя обстоятельствами. Порядок входа разный во всех ситуациях. Прежние «линзы» (составы ролей поверх мест) упразднены: роль = конкретный участник ситуации.
- **Ход раунда:** ситуация → первые позиции → обстоятельства 1, 2, 3 → поиск решения (ресурс по желанию) → рефлексия. 15 мин: обстоятельства 2 и 3 вместе; 90 мин: два раунда по 40 + перерыв + итог. Вторая попытка с обязательным ресурсом заменена постепенным раскрытием — новая механика сама даёт сравнение «до/после».
- **Скрытое не раскрывается заранее:** ни в онлайн-интерфейсе (закрытые карточки без названия роли), ни на карточке ситуации в печати (только первые роли и число остальных), ни в каталоге (обстоятельства — под спойлером «Для ведущего»).
- **Игроков не столько, сколько ролей:** первые роли — разным участникам, поздние — по кругу; ведущий переназначает; режимы «сцена», «совет коллег», «один участник». Свободные — наблюдатели.
- **Аудит ситуаций:** см. `docs/CARD_REGISTRY.md`. С-15 и С-17 заменены, добавлены С-22–С-24.
- **Дизайн-система:** индиго / бирюза / лаванда и цвета ролей; Montserrat (заголовки) и Onest (текст) — локальные файлы OFL, без внешних запросов; мотив «маршрута» с метками ролей; иллюстрации — собственные SVG (`platform/art.js`). Тексты, логотип и иллюстрации Центра знаний «Машук» не использованы.
- **Печать:** карточки 99 × 140 мм, 4 на A4 без зазоров, безопасное поле 4 мм, обороты с указанием «когда входит роль» / «не открывать до сигнала» — колоду можно разложить рубашкой вверх. Раскладка (`platform/print-layout.js`) общая для конструктора на сайте и PDF-сборки (`npm run print:pdf`, файлы в игнорируемой `qa/print/`). Доступ к конструктору — прежний код автора (PBKDF2 + AES-GCM). На `localhost` предусмотрен режим `?preview=1` для проверки вёрстки — на GitHub Pages он не действует.
- **Сохранения:** schema 5; встречи прежних редакций не продолжаются (изменились роли), но их можно скачать файлом.
- `platform/content.json` заменён на `platform/pages/*.html` — содержательные страницы проще править. Старые `scripts/generate_pdf.py` и проверки прежнего интерфейса удалены.
