## Проверки

- `npm test` — реестр (допустимые роли, ≥5 ролей, 3 обстоятельства, вход каждой поздней роли ровно в одном обстоятельстве, уникальные порядки), движок (раскрытие на каждом этапе для всех ситуаций и форматов, распределение ролей для 1–40 участников, сохранение/восстановление), печать (комплекты кратны листу, совмещение сторон, карточка ситуации не раскрывает поздние роли), страницы, ссылки и якоря.
- `npm run check:browser` — 31 проверка в Chromium: полный проход 40 мин (на каждом этапе открыто ровно положенное число обстоятельств), 15 мин, 90 мин с 24 участниками и вторым раундом, один участник на телефоне 390 px без горизонтальной прокрутки, перезагрузка, экран для всех, итоги, отсутствие ошибок в консоли.
- `npm run print:pdf` — 312 карточек, 78 двусторонних листов A4; автоматическая проверка, что текст помещается во все лицевые и оборотные стороны. Страницы просмотрены визуально (растровые снимки): шрифты, поля, совмещение оборотов для переворота по длинному краю, листы ведущего. Печать из конструктора сайта даёт тот же макет.
- Просмотр страниц на ширине 1440 и 390 px.

## Финальный аудит с разных позиций

- **Арт-директор.** Единый язык: прописные гротескные заголовки с двухтоновым акцентом, пилюли, пины ролей, пейзаж и ленты; на печати — тот же цвет ролей и пины обстоятельств. Отказались от градиентных «AI-карточек» и случайных иконок: вся графика — из одного мотива.
- **UI/UX.** Главный экран отвечает на «что это» за 5 секунд; ход раунда показан на реальном примере. В игре — одна главная кнопка «Далее / Открыть обстоятельство», маршрут этапов кликабелен для ведущего, новое обстоятельство всегда сверху.
- **Frontend.** Без внешних зависимостей и запросов; шрифты с `font-display:swap`; `prefers-reduced-motion` отключает анимации; сгенерированные HTML проверяются CI.
- **Педагог / методист.** Ситуации повседневные; конфликт — не в каждой (С-04, С-18, С-23, С-24 — организационные и воспитательные). Решение принимается после того, как видна вся картина; рефлексия спрашивает о сдвиге понимания.
- **Педагог-психолог.** Роли детей в чувствительных ситуациях не требуют «играть эмоции»; психологическая работа с ребёнком — с согласия родителей; при сведениях об угрозе игра останавливается (отдельный раздел и строка на карточке ведущего).
- **Заместитель директора.** Полномочия соответствуют практике: дополнительная работа — с согласия, порядок выездов, согласия на публикацию изображений, положение о текущем контроле, нормы времени на домашние задания, порядок хранения телефонов. Ссылки на акты сформулированы осторожно: «сверяйтесь с действующей редакцией».
- **Ведущий мероприятия.** Есть всё для проведения без подготовки сайта: карточка «Ведущему» с ходом игры, таблицей распределения ролей для 2–5 игроков и границами ситуации; рубашки показывают, когда открывать каждую карточку.
- **Участник впервые.** На экране всегда видно: какой этап, что делать, кто говорит, сколько осталось. Личные карточки ролей на общем экране скрыты.

## Ограничения

- С реальными педагогами новая редакция не проверялась; первые встречи стоит провести с записью затруднений.
- Физическая двусторонняя печать не проверялась — сначала пробный лист в масштабе 100 %.
- Готовые PDF прежней редакции внутри зашифрованного пакета не обновлены (это требует кода автора); новая колода печатается из конструктора. PDF новой редакции собираются командой `npm run print:pdf` и не публикуются открыто.
- Мультиплеерных комнат нет.
