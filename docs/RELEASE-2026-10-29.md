# Проверка рабочей ветки 29.10.2026

## Реализовано
- Сохранены 62 карты и все 19 активных ситуаций. Добавлены явные дилеммы всем ситуациям и вопросы по профессиональным ролям. С-02 и С-11 упрощены: убраны отвлекающие числовые условия. С-09 теперь допускает разные причины невыполнения работы.
- Быстрые настройки 15/45/60 минут; дополнительные параметры свёрнуты. Обозначены общий экран и учёт ведущего.
- Индикатор прогресса, ожидаемый результат каждого этапа, дополнительная кнопка перехода у таймера.
- Итог раунда открыто показывает первую/вторую попытки, ресурс, решение и общий вывод всех команд.
- Таймер учитывает время до перерисовки; возврат на страницу ставит его на паузу. Повторный выбор текущего этапа не сбрасывает время.
- Импорт проверяет согласованность количества раундов, бюджета этапов и работающих часов.
- PDF включает дилеммы. Регламент инструкции получен из движка. Проверяются размеры A4, порядок оборотов, полнота текста; исправлен неполный последний лист.

## Фактически проверено
- npm run build, npm test, git diff --check: успешно.
- 16 групп тестов движка, 28 комбинаций печатной раскладки, маршруты/ссылки/якоря, контроллер сохранений и таймера.
- Автоматическое прохождение 15/45/60 минут с двумя командами, записью решений и восстановлением экспортированного состояния.
- Браузер: опубликованная главная и запуск; рабочая версия — пресет 15 минут, согласие, все десять этапов С-16, ввод первой/второй попытки, решения и рефлексии; блокировка перехода без ресурса; выбор ресурса; восстановление после перезагрузки; отображение итогов раунда. Это сценарная проверка агентом, не реальная педагогическая апробация. Финальный диалог завершения после перезапуска браузерной среды не проверен повторно.
- PDF: 64 страницы для каждого края переворота, 5 страниц инструкции; все карточки сохранены, переполнения по расчётам нет. Визуально просмотрены первый лист карточек и регламент ведущего. Физическая печать не выполнена.

## Блокеры полного релиза
1. Безопасная серверная авторизация не реализована: требуется согласование размещения API. Текущий AES-GCM пакет сохранён, не выдан за серверную защиту. Новый PDF-комплект пока не заменяет прежний зашифрованный пакет на сайте.
2. Нет кода автора для испытания правильного входа в старый пакет. Не проводился подбор кода.
3. Мобильные устройства, весь набор браузеров, консоль и все административные пути не прошли полную повторную проверку.
4. Изменения находятся в PR. Объединение и проверка GitHub Pages — после подтверждения автора.

## Предлагаемая архитектура для согласования
Сохранить сайт и репозиторий. Добавить отдельный HTTPS API на согласованном серверном хостинге: проверка кода и ограничение попыток на сервере; случайная краткоживущая сессия; защищённые конечные точки списка/скачивания актуальных PDF; отзыв сессии при выходе; закрытое файловое хранилище. Секреты только в настройках сервера, не в GitHub. Общедоступный каталог остаётся открытым: защищать можно выдачу комплекта, но нельзя обещать секретность опубликованных текстов. До выбора сервиса и согласования расходов развёртывание не выполнять.
