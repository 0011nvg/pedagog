# Обсуждение без форм и независимые команды

- От 1 до 20 команд, по 4–12 участников; состав каждой задаётся отдельно.
- При нехватке участников по умолчанию — совет коллег: все позиции сохраняются, дополнительные роли читаются последовательно. Наблюдатели получают задачу.
- Общая ситуация и таймер, отдельные распределения ролей и ресурсы; подсказки для сравнения решений и общей рефлексии.
- Категория выбирает случайную ситуацию; повтор исключается при наличии альтернатив. Ручной выбор сохранён.
- Убраны онлайн-записи, выгрузка и печать итогов. Сохранение этапа и настроек в браузере осталось.
- Шестой ресурс каждой ситуации — «Выбор без давления». «Пауза перед ответом» уже существует, поэтому не дублируется. Общая колода теперь содержит 16 ресурсов.
- Завершение с кнопками повторной игры и главной страницы.
- Методика объединена с «Об игре»; старый URL сохраняет переходы по якорям. Упрощён футер.

## Проверка

Пройдены npm run build, npm test, git diff --check. Новые тесты проходят 360 сочетаний всех 40 ситуаций, трёх форматов и трёх составов команд (включая 20 × 12), все этапы, восстановление и некорректные размеры.

В браузере вручную пройдены 40 минут с 4 участниками; 15 минут с командами 4/7/5; два раунда 90 минут на мобильной ширине 390px. Проверены таймер, пауза после перезагрузки, сохранённый ресурс, шесть ресурсов, рекомендации и завершение. Горизонтального переполнения на мобильной ширине нет.

Печатная раскладка всех карточек (334 стороны A4) проверена в браузере на переполнение. Исправлено переполнение таблицы распределения С-24; после исправления переполнений нет. Автотесты проверяют совмещение лицевых и оборотных сторон всех 40 комплектов. Код доступа и механизм печати/PDF сохранены. Реальный системный диалог «Сохранить PDF» и успешный вход по коду автора не проверялись: код не предоставлен, API браузера не предоставляет экспорт произвольной страницы в PDF.

Автоматический Playwright-сценарий обновлён под новый интерфейс; в этой среде проверки взаимодействий выполнялись через доступный браузерный инструмент, без запуска этого отдельного сценария.
