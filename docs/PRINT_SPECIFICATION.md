# Печать: текущее состояние и следующий контракт

Текущий комплект: 62 уникальные карты, 9 позиций на A4, 7 двусторонних листов, 14 страниц; карточка 63×88 мм, зазор 2 мм, поля около 8,5 и 14,5 мм. Лица и обороты чередуются. Для длинного края зеркалируются столбцы, ID присутствует на обороте. Основной текст 9–10 pt. Есть пробный лист, карта роста и инструкция. Это офисный макет без типографских вылетов.

Указанное подтверждено существующим generate_print.py и сохранённым print-qa.json; реальные принтеры не проверялись. Предыдущий визуальный просмотр PDF не заменяет тест физического совмещения.

| Требование | Сейчас | Дальнейшее решение |
|---|---|---|
| Печать всей колоды | Готовый PDF | Сохранить как быстрый вариант |
| Выбор ID и категорий | Отсутствует | Выбор карт после открытия доступа |
| Несколько экземпляров роли | Отсутствует | Количество экземпляров и готовые наборы по ситуации |
| Длинный край | Подготовлен | Сохранить контрольный шаблон |
| Короткий край | Отсутствует | Отдельная трансформация оборотов с контрольными ориентирами; не переиспользовать PDF длинного края |
| Калибровка | Отсутствует | Независимые X/Y смещения оборота в мм с наглядным пробным листом |
| Полные паспорта | Только на сайте | Отдельная печатная книга ведущего той же редакции |
| Крупный шрифт | Нет альтернативы | Дополнительный увеличенный формат, не уменьшение текста до нечитаемого размера |
| Типографская версия | Отсутствует | Только после согласования формата, вылетов и требований конкретной типографии |

Для генератора рекомендована клиентская сборка PDF из единого реестра после расшифровки печатного пакета. Отбор на сайте должен включать не только ID, но и число экземпляров. Код не следует проверять простым сравнением с открытой строкой. Секрет и незашифрованные платные файлы не включать в публичные коммиты.

Общий код можно передать, а PDF скопировать: это не DRM и не персональный отзыв доступа. Нужда в индивидуальных кодах — отдельное продуктовое решение, требующее серверной архитектуры.

Приёмка: 1, 8, 9, 10, 18, 62 карты; дубли ролей; пустые позиции; оба края; крайние разрешённые смещения; соответствие ID; A4 и 100%; отсутствие текстового переполнения; длинные русские заголовки; проба на реальном принтере. Непроверенные варианты нельзя отмечать как поддерживаемые.
