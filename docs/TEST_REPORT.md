## Ограничение существующих тестов

Упрощённый DOM возвращает пустые списки из querySelectorAll. Обработчики вкладок, раскрытия ролей и элементов маршрута поэтому не проверяются как реальные элементы браузера. Тест случайной раздачи подтверждает следование roleSets; он не доказывает, что roleSets педагогически верны.

## Воспроизводимые дефекты

Команда: `node docs/checks/audit-probe.cjs`.

- A01: С-17 получает «Первую попытку» несмотря на запрет инсценировки в паспорте.
- A05: на этапе7 второго цикла сохраняются ресурс и поворот первого, если не нажать применение ситуации.
- A06: после применения С-16 во втором цикле возврат к подготовке первого оставляет С-16.
- A02: С-03, С-14 и С-20 имеют составы с повтором ID роли; один комплект физических карт не содержит двух экземпляров.

Это диагностические проверки нынешнего поведения. После исправления ожидаемые утверждения следует изменить на контракт корректного поведения, а диагностические результаты сохранить как историю.
