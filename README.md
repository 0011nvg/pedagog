# ПЕДАГОГ
Автор: Виктория Геннадьевна Науменко.

## Сайт
https://0011nvg.github.io/pedagog/

Главная: философия игры, семь авторских принципов, устройство колоды, пример двух попыток и возможные итоги.
Проведение: три формата (60/90/120 минут), маршрут, готовность, совместимые роли, таймер, подсказки, пауза и завершение.
Колода: 62 карточки и полные паспорта 19 ситуаций. С-07 исключена; другие коды сохранены.
Руководство: подготовка, правила безопасности, реплики ведущего, трудные моменты, общий итог и FAQ.
Печать: четыре PDF, открываемые кодом автора.

## Разработка
Исходники находятся в src. Выполните `node src/test.cjs`, затем `node src/build.cjs`.
Сборка создаёт src/PEDAGOG_v2.html. Для публикации скопируйте её в корневой index.html.
Рядом с опубликованным index.html должен находиться print-pack.js.
В исходном src/index.html путь к print-pack.js разрешается в папке src; для локальной проверки положите туда копию публичного файла.
Обновляя текст карточки, синхронизируйте deck.js, её печатную редакцию и зашифрованный комплект.
editorial.html, guide-extra.html и print-section.html — редакционные фрагменты; актуальные копии уже включены в index.html. Автоматически при сборке не подставляются.

## Печатный комплект и доступ
PDF A4: 62 карточки 63×88 мм, 9 позиций на листе, 7 листов / 14 чередующихся страниц, обороты зеркально расположены для длинного края. Отдельно: пробный лист, карта роста и инструкция.
Это офисный макет без типографских вылетов. Перед тиражом обязательно проверить реальный принтер.

print-pack.js содержит только зашифрованный PDF-комплект (AES-GCM, ключ из кода через PBKDF2).
Открытый код доступа и исходные PDF НЕ размещаются в этом репозитории.
Это общий код, а не личный кабинет: нет оплаты, индивидуального отзыва или ограничения числа скачиваний. Получатель может передать код или скачанный файл. Тексты каталога публичны.
Для открытия комплекта нужен современный браузер с WebCrypto и HTTPS. Код не сохраняется.

## Данные и ограничения
Ответы участников не собираются. В localStorage сохраняется только состояние сессии; после перезагрузки таймер на паузе.
Одно устройство ведёт общую сцену либо один стол, но не синхронизирует несколько столов.
Уместность кризиса и согласие группы проверяет ведущий; автоматический отбор — не замена этому решению.
Игра не предназначена для аттестации и диагностики; эффективность с реальными участниками не подтверждена.

## Выполненные проверки
62 карточки; поля 19 паспортов; ссылки совместимости; 1900 распределений ролей; суммы времени; этапы всех трёх форматов; пауза; завершение и сохранение; загрузка дополнительных функций в имитации DOM.
Правильный код расшифровывает четыре PDF через WebCrypto; неправильный отвергается.
Проверены геометрия PDF, зеркальная раскладка, соответствие ID и рендер страниц.
Это не проверка в настоящем браузере: нужны Chrome/Safari, клавиатура, мобильный экран, перезагрузка и печать на реальном устройстве. Испытания с людьми не проводились.

Исходные авторские HTML/PPTX сохранены без изменений. Условия использования на сайте перенесены из авторской разработки; новая юридическая экспертиза не проводилась.
