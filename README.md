# ПЕДАГОГ · версия 2.0

Автор: Виктория Геннадьевна Науменко.

Деловая игра и цифровой помощник ведущего: три формата, 62 карточки, подбор совместимых ролей и ресурсов, таймер и рефлексия.

## Запуск

Автономный сайт находится в `index.html`. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → main → / (root).

## Исходники

Редактируемые файлы находятся в `src/`. Проверка: `node src/test.cjs`. Сборка: `node src/build.cjs`; результат `src/PEDAGOG_v2.html` следует скопировать в корневой `index.html`.

## Статус

Редакция для пилота. Логические проверки выполнены; браузерные испытания и реальные пилоты ещё необходимы. Печатная колода предыдущей версии требует синхронизации. Личные ответы не собираются; состояние сессии сохраняется только в браузере.
