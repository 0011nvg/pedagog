# ПЕДАГОГ

Авторская профессиональная игра Виктории Геннадьевны Науменко.

**Сайт:** https://0011nvg.github.io/pedagog/

## Структура

Девять самостоятельных страниц: главная, об игре, онлайн-игра, печать, библиотека ситуаций, роли и ресурсы, правила, методический кабинет, автор. Старые ссылки с `#about`, `#session`, `#deck`, `#guide`, `#print` сохранены через переходы.

Все 64 карты редакции 3.0 (29.10.2026) — в `src/deck.js`: 20 ситуаций (С-07 исключена автором), 9 ролей (включая наблюдателя), 15 ресурсов, 10 поворотов, 10 вопросов рефлексии. Что изменено в каждой карточке и почему — `docs/CARD_REGISTRY.md`.

## Разработка и проверки

Node.js 18+; внешние npm-пакеты для сборки и тестов не нужны.

```sh
npm run build
npm test
```

Сборка создаёт HTML в корне для GitHub Pages и игнорируемую копию `qa-preview/` для локальной проверки. Информационные страницы берутся из `platform/content.json`, игровые данные — из `src/deck.js`, тема/сложность — из `platform/metadata.js`. Не правьте сгенерированные страницы вручную.

GitHub Actions проверяет сборку, инварианты игры, печатную раскладку и соответствие опубликованных HTML исходникам. Подробности: `docs/ARCHITECTURE-2026.md`, `docs/SESSION.md`, `docs/PRINT-2026.md`, `docs/RELEASE-2026-10-26.md`.

## Онлайн-игра

Три формата — 15, 40 и 90 минут. Регламент задан один раз в `platform/engine.js` (`FORMATS`) и из него же строятся таблицы в правилах и печатной инструкции. Стартовая форма: время, число участников (1–40), ситуация. Команды по 4–6 человек формируются автоматически при 13+ участниках; один участник работает без сцены.

Раунд: ситуация и позиции → первая попытка → что заметили → ресурс → вторая попытка → сравнение последствий → решение → личный вывод. В 15 минутах наблюдения объединены с ресурсом, сравнение — с решением. 90 минут: два раунда по 45 (перерыв, затем общий итог). Ко второй попытке нельзя перейти без ресурса у каждой команды.

Игра идёт с одного экрана, сетевой синхронизации нет. Состояние хранится в localStorage (ключ `pedagog-platform-session-v4`); после перезагрузки встреча открывается на том же этапе, таймер на паузе. Итоги: .txt, печать, файл .json для переноса. Сохранения прежней версии (v3) не открываются, но их можно скачать.

## Печать

Доступ к печатному конструктору — по прежнему коду автора (PBKDF2 + AES-GCM в браузере; код не хранится). Это барьер, а не защищённый административный доступ: GitHub Pages — статический хостинг, тексты карточек открыты в «Материалах». Готовые PDF внутри `print-pack.js` — прежней редакции и так подписаны. Конструктор печатает актуальную колоду 3.0 и листы ведущего с регламентом из `FORMATS`.

`python3 scripts/generate_pdf.py` создаёт в игнорируемой `qa/print/` актуальный комплект: карточки для переворота по длинному и короткому краю (72 стр., первый лист — пробный), руководство ведущего, правила участника, бланк результатов, `geometry.json` с проверками. Физическая двусторонняя печать не проверялась — сначала пробный лист в масштабе 100 %. Подробности: `docs/PRINT-2026.md`.

## Границы проверки

Программные и браузерные проверки не заменяют реальные педагогические испытания и физическую двустороннюю печать. Эффективность обучения, успешность реальных переговоров и готовность сервера многопользовательских комнат не заявляются.
