# ПЕДАГОГ

Авторская профессиональная игра Виктории Геннадьевны Науменко.

**Сайт:** https://0011nvg.github.io/pedagog/

## Структура

Девять самостоятельных страниц: главная, об игре, онлайн-игра, печать, библиотека ситуаций, роли и ресурсы, правила, методический кабинет, автор. Старые ссылки с `#about`, `#session`, `#deck`, `#guide`, `#print` сохранены через переходы.

Все 62 активные карты из существующей версии сохранены в `src/deck.js` без изменения текстов. С-07 ранее исключена автором. Инвентаризация исходных HTML/PPTX и различия редакций — `docs/INVENTORY-2026-10-26.md`. Исходные редакционные файлы `src/` не удалены.

## Разработка и проверки

Node.js 18+; внешние npm-пакеты для сборки и тестов не нужны.

```sh
npm run build
npm test
```

Сборка создаёт HTML в корне для GitHub Pages и игнорируемую копию `qa-preview/` для локальной проверки. Информационные страницы берутся из `platform/content.json`, игровые данные — из `src/deck.js`, тема/сложность — из `platform/metadata.js`. Не правьте сгенерированные страницы вручную.

GitHub Actions проверяет сборку, инварианты игры, печатную раскладку и соответствие опубликованных HTML исходникам. Подробности: `docs/ARCHITECTURE-2026.md`, `docs/SESSION.md`, `docs/PRINT-2026.md`, `docs/RELEASE-2026-10-26.md`.

## Онлайн-игра

Настройки 1–40 участников, 1–8 команд, 20/45/60/90/120 минут. Полный цикл двух попыток, совместимые роли с ситуационными позициями, ресурсы, повороты с предусловиями, таймер, общие записи и рефлексия. У каждой команды и раунда свои данные. С-17 всегда обсуждается без инсценировки. Недостаточное число исполнителей автоматически переводит работу в совет коллег.

Состояние и введённые общие заметки сохраняются локально. Восстановление ставит таймер на паузу. JSON можно экспортировать и импортировать; текстовый итог включает общие записи. Не вводите личные сведения. Сетевая синхронизация и комнаты с кодами **не реализованы**; серверная архитектура описана отдельно.

## Печать

Доступ по прежнему коду автора. `print-pack.js` не изменён; пароль не хранится. Готовые PDF предыдущей редакции доступны после расшифровки. Новый конструктор использует актуальные полные карточки общего реестра: фильтры, выбор ID, экземпляры, повторные роли, A4/A3, оба края переворота, калибровка и бланки.

Полный паспорт требует крупной карточки 190 × 132 мм. Исходные маленькие карточки не заменены и остаются в прежнем PDF. Выбранный актуальный набор сохраняется через диалог браузера «Печать → Сохранить как PDF»; прямой PDF-экспорт нового набора не заявляется.

`python scripts/generate_pdf.py` (ReportLab + pypdf, DejaVu Sans) генерирует проверочные полнотекстовые PDF только в игнорируемой `qa/print/`. Они не публикуются открыто. До тиража нужна физическая проба принтера в масштабе 100%.

Общий код не является персональной лицензией или платёжной системой. Тексты каталога публичны. Секреты и незашифрованный закрытый комплект в репозитории отсутствуют.
